## Next up

Right now Aetherforge is a general ground control station. It would look the same for
search and rescue or site inspection. The feature that makes it useful for farms is
**coverage-path planning**: draw a field boundary, and it generates a spray or scan pattern
that accounts for swath width, overlap and obstacles.

## Real hardware

I'm assembling a [Holybro X500 v2](/drones/x500/) running PX4, so the same backend can move
from simulated telemetry to a real aircraft.

## Longer term

A tool for small drone spray operators that puts mission planning and compliance record
keeping in one place, and works with any drone manufacturer.

Why agriculture? It matters, and I really like food.
